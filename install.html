보고잡지 앱 설치 안내 (베타)

베타 테스트 버전이라 아직 스토어에 없어요. 아래 방법으로 직접 설치해 주세요.

테스트 중 발견한 문제나 의견은 [피드백 받을 곳: 카카오톡 오픈채팅 링크 또는 메일]로 알려 주세요.

안드로이드 (갤럭시 등)

휴대폰에서 이 페이지를 열고 아래 버튼을 누르세요. 컴퓨터에서는 설치되지 않아요.

보고잡지 APK 내려받기

  1. 내려받기 버튼을 누르면 Expo 페이지가 열려요. 거기서 Install(설치)을 누르세요. "이 유형의 파일은 휴대전화에 해를 끼칠 수 있습니다" 안내가 떠도 다운로드를 누르면 돼요.
  2. 다운로드가 끝나면 알림창 또는 파일 앱 → 다운로드 폴더에서 bogomagazine…apk 파일을 누르세요.
  3. "출처를 알 수 없는 앱 설치" 창이 뜨면 설정 → 이 출처 허용을 켜고 뒤로 돌아오세요. 처음 한 번만 물어봐요.
  4. 설치를 누르고 끝나면 열기.
  5. 카카오 또는 Apple 계정으로 로그인하고, 이름과 관계를 고르면 끝이에요. 초대 링크를 받았다면 로그인 뒤 그 링크를 다시 눌러 주세요.

설치가 안 될 때

  • "앱이 설치되지 않았습니다": 이전 테스트 버전이 있으면 먼저 지우고 다시 설치해 주세요.
  • Play 프로텍트 경고: "자세히 알아보기" → "무시하고 설치"를 누르면 돼요. 스토어 밖에서 받는 앱이라 뜨는 안내예요.
  • 삼성 인터넷에서 다운로드가 막힐 때: Chrome으로 열어 보세요.

아이폰

아이폰은 Apple의 TestFlight를 통해 설치해요.

  1. App Store에서 TestFlight 앱을 먼저 설치하세요.
  2. 아래 초대 링크를 아이폰에서 눌러 수락 → 설치.
    [TestFlight 공개 링크: 준비되면 넣기]
  3. 이후 새 버전이 나오면 TestFlight 앱에서 업데이트만 누르면 돼요.

자주 묻는 것

  • 통신사 데이터가 드나요? 설치 파일은 약 100MB 안팎이라 와이파이에서 받는 걸 권해요.
  • 기존 앱과 다른가요? 베타 버전은 자주 바뀌어요. 새 링크를 받으면 같은 방법으로 덮어 설치하면 되고, 데이터는 유지돼요.
  • 개인정보는요? 개인정보 처리방침을 확인해 주세요.
