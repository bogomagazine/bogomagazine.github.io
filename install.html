보고잡지 앱,
이렇게 설치해요

아직 앱 가게(스토어)에 올라가기 전이라 이 페이지에서 직접 설치해요. 천천히 따라오시면 5분이면 끝나요.

꼭 휴대폰에서 열어 주세요. 컴퓨터에서는 설치가 안 돼요. 카카오톡으로 받은 링크를 휴대폰에서 눌렀다면 잘 오신 거예요.

어떤 휴대폰을 쓰시나요?

1. 여기를 눌러 설치 파일 받기

  1. 위 주황색 버튼을 누르세요

    영어로 된 화면이 하나 열려요. 거기서 Install 글자를 누르면 돼요.

    "이 유형의 파일은 휴대전화에 해를 끼칠 수 있습니다"라는 말이 떠도 괜찮아요. 다운로드를 누르세요. 가게 밖에서 받는 앱이라 늘 나오는 안내예요.

  2. 받은 파일을 여세요

    화면 맨 위를 아래로 쓸어내리면 다운로드 완료 알림이 있어요. 그걸 누르세요.

    알림을 못 찾겠으면 내 파일 앱 → 다운로드 폴더에서 bogomagazine으로 시작하는 파일을 누르세요.

  3. "허용"을 켜 주세요

    "출처를 알 수 없는 앱" 또는 "이 출처 허용"이라는 창이 뜨면 설정을 누르고, 스위치를 켜서 허용으로 바꾼 다음 뒤로가기(◁)를 누르세요.

    처음 한 번만 물어봐요.

  4. 설치하고 여세요

    설치를 누르고 잠시 기다리면 끝나요. 그다음 열기.

    "Play 프로텍트" 경고가 뜨면 자세히 알아보기 → 무시하고 설치를 누르면 돼요.

  5. 로그인하면 끝이에요

    노란 카카오로 시작하기 버튼을 누르고, 내 이름과 가족 관계(딸·사위·손녀 같은)를 고르세요.

    가족에게 초대 링크를 받으셨다면, 로그인한 뒤 카카오톡에서 그 링크를 한 번 더 눌러 주세요. 그러면 우리 가족방에 들어가져요.

아이폰은 애플이 만든 TestFlight(테스트플라이트)라는 앱을 거쳐 설치해요.

  1. 먼저 TestFlight 앱을 받으세요

    App Store를 열고 위 검색창에 TestFlight라고 치세요. 파란 바탕에 하얀 프로펠러 그림이에요. 받기를 누르세요.

  2. 아래 초대 링크를 누르세요

    [TestFlight 공개 링크: 준비되면 넣기]

    TestFlight가 열리면 수락 → 설치를 누르면 돼요.

  3. 보고잡지를 열고 로그인하세요

    홈 화면에 생긴 보고잡지를 누르고, 카카오로 시작하기 또는 검은 Apple로 계속하기를 누르세요. 그다음 이름과 가족 관계를 고르면 끝이에요.

새 버전이 나오면 TestFlight 앱에 업데이트 버튼이 생겨요. 그것만 누르면 돼요.

막혔을 때

"앱이 설치되지 않았습니다"라고 떠요

전에 받아 둔 보고잡지가 있으면 그것부터 지우고(앱을 길게 눌러 "설치 삭제") 1번부터 다시 하세요.

다운로드 버튼이 아무 반응이 없어요

삼성 인터넷 대신 Chrome(크롬)으로 이 페이지를 열어 보세요. 주소를 길게 눌러 복사한 뒤 크롬에 붙여 넣으면 돼요.

데이터가 많이 들까요?

설치 파일은 사진 몇십 장 정도 크기예요. 와이파이가 되는 곳에서 받으시면 걱정 없어요.

내 정보는 안전한가요?

어떤 정보를 왜 받는지 개인정보 처리방침에 전부 적어 두었어요. 사진은 우리 가족만 볼 수 있어요.

그래도 어려우면 가족에게 이 페이지를 보내 주세요 같이 보면서 하면 금방이에요. 궁금한 점은 [피드백 받을 곳: 오픈채팅 링크 또는 메일]로 알려 주세요.
